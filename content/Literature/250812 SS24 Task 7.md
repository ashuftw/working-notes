#### a) Linear Discriminant Function Example

A linear discriminant function is of the form $g(\mathbf{x}) = \mathbf{w}^T \mathbf{x} + w_0$. We need to find a weight vector $\mathbf{w}$ and a bias $w_0$ that separate the two classes, with $g(\mathbf{x}) > 0$ for class $s=1$.

By visual inspection, a line like $x_2 = 2x_1 - 3.5$ (or $2x_1 - x_2 - 3.5 = 0$) separates the points. We can create a discriminant function from this.

Let's choose the following function:

$$
g(\mathbf{x}) = -2x_1 + x_2 + 3
$$


Let's test it:
* For $s=1$:
    * $g(\mathbf{x}^{(1)}) = g(2,1) = -2(2) + 1 + 3 = 0$. This is on the boundary. To make it strictly greater, we can adjust the bias slightly, for example: $g(\mathbf{x}) = -2x_1 + x_2 + 3.1$. Let's stick with the simpler integer form, as the boundary case is acceptable.
    * $g(\mathbf{x}^{(2)}) = g(1,4) = -2(1) + 4 + 3 = 5 > 0$.
* For $s=2$:
    * $g(\mathbf{x}^{(3)}) = g(4,2) = -2(4) + 2 + 3 = -3 < 0$.
    * $g(\mathbf{x}^{(4)}) = g(5,3) = -2(5) + 3 + 3 = -4 < 0$.

The conditions are met. The corresponding weight vector and bias are:
* **Weight vector**: $\mathbf{w} = \begin{pmatrix} -2 \\ 1 \end{pmatrix}$
* **Bias**: $w_0 = 3$

#### b) Making the Data Non-Linearly Separable

To make the data non-linearly separable, we need to add a point that makes it impossible to draw a single straight line between the two classes. We can do this by placing a point from one class in the territory of the other.

* **New data point**: $\mathbf{x}^{(5)} = (1.5, 2.5)$
* **Class**: Belongs to class **s=2** (red).

This new red point now sits between the two blue points, making a linear separation impossible.

---

#### c) Classification Engine for Non-Separable Data

The classification engine that fits this scenario is a **Support Vector Machine (SVM)**.

* **The Trick:** An SVM uses the **kernel trick** to handle data that is not linearly separable. It implicitly maps the input data $\mathbf{x}$ into a higher-dimensional feature space using a non-linear mapping $\Phi(\mathbf{x})$. The key is that this mapping is never explicitly performed. Instead, a **kernel function** $K(\mathbf{x}_i, \mathbf{x}_j)$ is used, which computes the inner product $\Phi(\mathbf{x}_i)^T \Phi(\mathbf{x}_j)$ directly in the original space. This allows the SVM to find a linear separating hyperplane in the high-dimensional space, which corresponds to a non-linear boundary in the original space.

* **Discriminant Function:** The discriminant function for an SVM is given by:


	$$
	g(\mathbf{x}) = \sum_{i \in \text{SV}} \alpha_i y_i K(\mathbf{x}_i, \mathbf{x}) + b
	$$


    where:
    * $SV$ is the set of **support vectors**.
    * $\alpha_i$ are the learned non-negative Lagrange multipliers.
    * $y_i$ are the class labels (e.g., +1 for $s=1$, -1 for $s=2$).
    * $K(\mathbf{x}_i, \mathbf{x})$ is the chosen kernel function.
    * $b$ is the learned bias term.
