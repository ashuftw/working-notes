### a) Building Blocks of the LSTM

The four marked grey building blocks in the LSTM diagram are:

* **A: Constant Error Carousel**: "Memory cell" -> allows information to flow through the network largely unchanged over long sequences.
* **B: Input Gate**: Decides what new information to store in the cell
* **C: Forget Gate**:  Decides what information to discard from the cell 
* **D: Output Gate**: Decides what information from the cell to use for the output at the current time step. 

---
### b) Training an LSTM

LSTMs are trained using a modified version of the backpropagation algorithm called **Backpropagation Through Time (BPTT)**.

The core idea is to **unfold the recurrent network** over several time steps, effectively creating a deep feedforward network where the weights are shared across all time steps. Standard backpropagation is then applied to this unfolded network to calculate the gradients and update the weights. The LSTM's internal "Constant Error Carousel" (CEC) structure allows the error gradient to flow back through many steps without vanishing, enabling the network to learn long-term dependencies from the data.

> Note: Error Gradient is a signal that tells each how the weights of the adjustable part of the network should change in order to accommodate for new data.  

---
### c) LSTM vs. Standard RNN: A Practical Task

A practical task where an LSTM is more advantageous than a standard RNN is **machine translation**, especially for long sentences.

* **Why LSTM is better suited:** Standard RNNs suffer from the **vanishing gradient problem**, making it difficult for them to learn dependencies between words that are far apart in a sentence. 
* LSTMs solve this with their memory cell and gating mechanism. The **forget gate** can learn to hold onto the "plural" status of the subject for many time steps, and the **output gate** can access this memory when it's time to generate the correct translation. This ability to selectively remember and forget information over long sequences makes LSTMs far superior for tasks requiring long-range context.
