## **Core Topics to Master**

### **1. Python Fundamentals (Exercise 1)**

- **Data types**: integers, floats, complex numbers, strings
- **Basic operations**: arithmetic, logical operators, string manipulation
- **Input/Output**: `print()`, `input()`, formatted strings (f-strings, .format())
- **Control structures**: if/elif/else statements, for/while loops
- **Lists and operations**: append, indexing, slicing

### **2. Advanced Data Structures (Exercise 2)**

- **Lists vs Tuples**: mutability, operations
- **Dictionaries**: key-value pairs, accessing data
- **File I/O**: reading/writing text and Excel files with `openpyxl`
- **Functions**: definition, parameters, return values, default arguments
- **String methods**: replace(), find(), count()

### **3. NumPy & Linear Algebra (Exercise 3)**

- **Array creation**: `np.array()`, `np.zeros()`, `np.ones()`, `np.linspace()`
- **Matrix operations**: multiplication, transpose, determinant, inverse
- **Solving linear systems**: `np.linalg.solve()`, `np.linalg.inv()`
- **Array indexing and slicing**

### **4. Matplotlib Visualization (Exercise 3)**

- **Basic plotting**: `plt.plot()`, axis labels, titles, legends
- **Subplots**: `plt.subplot()`, multiple plots in one figure
- **Plot customization**: colors, line styles, markers
- **Logarithmic scales**: `plt.semilogx()`, `plt.semilogy()`, `plt.loglog()`

### **5. Object-Oriented Programming (Exercise 4)**

- **Class definition**: `__init__()`, attributes, methods
- **Encapsulation**: private/protected attributes (`_attribute`)
- **Magic methods**: `__repr__()`, `__add__()`, `__gt__()`, `__lt__()`
- **Properties**: getters, setters with `@property`
- **Inheritance**: base classes, derived classes

### **6. Polynomial Fitting & Systems of Equations (Exercise 5)**

- **Curve fitting**: `np.polyfit()`, `np.polyval()`, `scipy.optimize.curve_fit()`
- **Linear systems**: `np.linalg.solve()`, `np.linalg.lstsq()`
- **Data analysis**: statistical evaluation, error calculation

### **7. Differential Equations (Exercise 6)**

- **ODE solving**: `scipy.integrate.solve_ivp()`, `scipy.integrate.odeint()`
- **System setup**: converting higher-order ODEs to first-order systems
- **Physical modeling**: spring-mass systems, electrical circuits

### **8. FFT & Signal Processing (Exercise 7)**

- **Fast Fourier Transform**: `numpy.fft.fft()`, frequency analysis
- **Signal filtering**: Butterworth filters, frequency domain manipulation
- **Sampling theory**: aliasing effects
