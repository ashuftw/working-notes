#### a) Obtaining the Activation Input Vector

To obtain the input vector **v** (also known as the logits or pre-activation vector) for the final layer's activation function, you perform a matrix-vector multiplication between the output layer's weight matrix **A** and the input vector **y** (which is the output from the previous hidden layer). A bias vector **b** is typically added as well.

The formula is:

$$
\mathbf{v} = \mathbf{A} \cdot \mathbf{y} + \mathbf{b}
$$


Where:
* **v**: The resulting input vector for the activation function.
* **A**: The weight matrix of the output layer.
* **y**: The feature vector input to the output layer.
* **b**: The bias vector for the output layer.

---

#### b) Activation Function and Class Prediction

**Activation Function:**
For a multi-class classification problem like this, the most appropriate activation function for the output layer is the **Softmax** function. It converts the raw scores in vector **v** into a probability distribution over the classes.

The formula for the Softmax function is:

$$
\text{softmax}(\mathbf{v})_i = \frac{e^{v_i}}{\sum_{j=1}^{K} e^{v_j}}
$$

where $K$ is the number of classes (here, $K=5$) and $v_i$ is the $i-$th element of the input vector **v**.

**Class Prediction:**
The predicted class corresponds to the neuron with the highest activation score in the vector **v**.
Given the vector:

$$
\mathbf{v} = (0.7, -0.5, 2.75, -0.3, 2.25)^T
$$

The components correspond to the classes: (apple, cherry, orange, blueberry, grapefruit).

The maximum value in **v** is **2.75**, which is the third element. Therefore, the network predicts class **s=3: orange**.

**Why Calculation is Unnecessary:**
There is no need to calculate the actual probability values using the softmax formula to determine the predicted class. This is because the softmax function is **monotonically increasing**. This property ensures that the order of the values is preserved; if $v_i > v_j$, then it is guaranteed that $\text{softmax}(\mathbf{v})_i > \text{softmax}(\mathbf{v})_j$.

Therefore, the index of the maximum value in the input vector **v** will be the same as the index of the maximum probability in the output vector. We can find the winning class simply by finding the maximum value in **v** before the activation (`argmax(v)`).
