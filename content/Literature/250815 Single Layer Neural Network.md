It is a type of neural network that uses a set of [[250815 Linear Discriminant Function|linear discriminant functions]] to classify an input feature vector. It consists of an **input layer** representing the features and an **output layer** where each node corresponds to a specific class. The network makes a decision by selecting the class associated with the output node that produces the highest value.
