It is a mathematical function whose graph has a S-shaped or **sigmoid curve**.
## Logistic Function
A common example for a function whose output is a sigmoid is given by

$$
\sigma(x) = \frac{1}{1 + e^{-x}} = \frac{e^x}{1 + e^x} = 1 - \sigma(-x)
$$
